# Purchasing Alignment Monitor

AI-powered healthcare purchasing alignment monitoring system using AWS Bedrock and LangGraph.

## 🎯 Objective

Identifies hospitals whose purchasing behavior is not aligned with vendor contract rules through RAG (Retrieval-Augmented Generation).

ALL OF THE EXAMPLE DATA IS FAKE AND GENERATED BY AI

**Key Features:**
- Retrieves vendor contract rules and product catalog from Bedrock Knowledge Base
- Analyzes quarterly purchase order data against contract pricing tiers ($800K-$1M)
- Detects purchasing misalignment patterns with risk classification
- Generates AI-powered insights using Amazon Nova Pro
- Creates visualizations (5 chart types) and comprehensive reports

## 🏗 Architecture Diagram

![Purchasing Alignment Monitor Architecture](architecture_diagram.svg)

The workflow follows a **5-step LangGraph process**:

1. **Retrieve Contract Rules** - Extract pricing tiers and compliance requirements via `retrieve_and_generate`
2. **Retrieve Product Catalog** - Load Branded Rx, Generic, and OneStop products with NDC codes
3. **Retrieve PO Data** - Fetch purchase orders using `retrieve` API with CSV reconstruction
4. **Analyze Alignment** - Detect violations (off-contract, tier mismatch, price deviation) and assign risk levels
5. **Generate AI Insights** - Amazon Nova Pro provides per-hospital recommendations and executive summary

### Architecture Layers

| Layer | Components |
|-------|------------|
| AWS Infrastructure | S3, Bedrock KB, Bedrock LLM (Nova Pro), Agent Runtime |
| KB Content | Contract Rules, Product Catalog (20 products), Purchase Orders |
| LangGraph Workflow | 5 sequential agent nodes with state management |
| Risk Detection | Off-Contract, Below Tier, Price Deviation, Tier Mismatch |
| AI Insights | Per-Hospital Analysis, Executive Summary, Visualizations |
| Outputs | CSV Report, Text Report, 5 Visualization Charts |

## 🔍 Alignment Analysis Logic

The system detects misaligned hospitals by analyzing:

### Detection Criteria

1. **Off-Contract Purchases** → Risk: HIGH
   - Drugs purchased that aren't in the vendor's contracted drug list

2. **Price Deviations** → Risk: MEDIUM
   - Unit prices exceed contracted rates (>10% variance)

3. **Tier Mismatches** → Risk: MEDIUM
   - Hospital using wrong contract tier classification

4. **Spend Below Minimum** → Risk: MEDIUM
   - Annual spend below $800K minimum tier threshold

### Risk Levels

- **LOW**: Minor price deviations only
- **MEDIUM**: Tier mismatch or below-minimum spend
- **HIGH**: Off-contract drug purchases or multiple violations

## 🏗️ Workflow Architecture

### Execution Flow (5-Step LangGraph Pipeline)

```
START
  ↓
[Step 1: Retrieve Contract Rules]
  │ Uses: retrieve_and_generate API
  │ Extracts:
  │ - Pricing tier thresholds ($800K-$900K-$1M)
  │ - Discount percentages per tier
  │ - Compliance requirements
  ↓
[Step 2: Retrieve Product Catalog]
  │ Uses: retrieve_and_generate API
  │ Loads:
  │ - Branded Rx products (10)
  │ - Generic products (9)
  │ - OneStop products (1)
  │ - NDC codes, WAC & contract prices
  ↓
[Step 3: Retrieve PO Data]
  │ Uses: retrieve API (raw chunks)
  │ Returns:
  │ - Hospital purchase records
  │ - Drug NDCs & quantities
  │ - Unit prices & totals
  │ - Contract tiers applied
  ↓
[Step 4: Analyze Alignment]
  │ For each hospital:
  │ - Check off-contract purchases
  │ - Validate tier pricing
  │ - Calculate spend vs thresholds
  │ - Assign risk level (LOW/MEDIUM/HIGH)
  ↓
[Step 5: Generate AI Insights]
  │ Uses: Amazon Nova Pro (invoke_model)
  │ Generates:
  │ - Per-hospital analysis (2-3 sentences)
  │ - Actionable recommendations (3-5 bullets)
  │ - Executive summary
  │ - 5 visualization charts
  ↓
[Output Generation]
  │ Creates:
  │ - misaligned_hospitals_*.csv
  │ - analysis_report_*.txt
  │ - visualizations/*.png
  ↓
END
```

### LangGraph State Management

```python
WorkflowState:
  contract_rules: str              # Parsed tier thresholds
  product_catalog: str             # 20 products with NDC/pricing
  purchase_order_data: str         # Raw PO CSV data
  parsed_po_data: list[dict]       # Structured PO records
  hospital_analyses: list[dict]    # Per-hospital analysis results
  misaligned_hospitals: list[dict] # Filtered misaligned only
  ai_insights: dict                # Nova Pro generated insights
  csv_output: str                  # CSV report content
  report: str                      # Full text report with AI
```

## 🐛 Troubleshooting

### AWS Authentication Error
```
Error: InvalidSignatureException
```
**Solution:** Verify AWS credentials in `.env` are correct and have Bedrock access.

### Knowledge Base Not Found
```
Error: ResourceNotFoundException
```
**Solution:** Check `KNOWLEDGE_BASE_ID` in `.env` and verify KB exists in your region.

### Missing Dependencies
```
Error: ModuleNotFoundError
```
**Solution:** Run `poetry install` to install all required packages.

### No Purchase Data Returned
```
Warning: No purchase order data to analyze
```
**Solution:** Verify Bedrock KB contains PO data in correct CSV format.
